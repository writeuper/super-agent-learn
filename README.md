# super-agent-learn

## 项目简介

super-agent-learn 是 DSH SuperAgent 的学习与实验项目，用于探索和实践智能体（Agent）在自动化任务调度、代码生成与评审等场景中的应用。项目基于 DSH（DeepSeek Harness）运行时，通过 Issue 驱动的协作工作流，展示 SuperAgent 从接收任务、分析上下文、执行实现到交付结果的全过程。

## 目录结构

```
super-agent-learn/
├── README.md          # 项目说明文档
└── ...                # 后续学习模块与示例代码
```

## 本地运行步骤

1. **克隆仓库**

   ```bash
   git clone https://github.com/writeuper/super-agent-learn.git
   cd super-agent-learn
   ```

2. **查看项目文档**

   ```bash
   cat README.md
   ```

3. **参与学习**

   通过 Issue 提交学习任务或实验需求，观察 SuperAgent 如何响应并完成任务。
